# 缩腹腹壁隆起影子切分：技术设计

## 已验证事实与决策

用户将顶点定义为吸气时腹部向外隆起最高的平台。现有 `phase_segmenter.py` 的缩腹信号是肩髋三维向量相对竖直的角度，不能代表腹壁外缘。398/399 的原视频已在本地找到并与关键点序列核对；基于肩髋点锚定的腹壁轮廓试验在 399 的 4.7、16.2 秒得到外凸峰，落在人工区间。两条原视频被 Git 忽略，不能作为常规 CI 依赖。两例同源视频不足以证明跨衣着或机位泛化。因此本次先实现可复现的视觉影子诊断，不自动替换正式次数与角度评分。

## 信号提取

新建 `app/core/abdominal_visual_signal.py`，输入原视频路径和 **未归一化** `visualization_frames`。对短缩腹片段（先设 30 秒上限）二次顺序解码，按现有姿态帧的原始 `frame_index` 采样，不重复运行 MediaPipe。超时长、不足帧或视频无法解码时返回带原因的不可用结果，而非抛出导致正式分析失败的异常。

每帧以左右肩和左右髋中点确定侧视躯干轴和肩髋横向跨度 L；用 x≈肩到髋横向距离的 68% 位置锚定腹部，取 ±1.8% L 的多个扫描列，沿 y≈肩髋中点−(35%…1.5%)L 的窗口寻找衣物/背景边缘。灰度背景参考取 y≈中点−33%L，衣物参考取 y≈中点−7%L，以两者灰度中点为自适应阈值；要求背景与衣物有足够亮度差、连续 6 个暗像素、≥70% 扫描列有效。多个列的边缘 y 中位数相对躯干中点归一化，方向统一为向外增大。保存采样值、有效比例、对比度中位数和失败原因；诊断中仅保存聚合统计与候选，不保存视频画面。

该亮度轮廓是保守代理，不是人体分割或生理收缩测量。若衣物与背景无法区分、视角不合适、躯干关键点低置信，主动退出到 `unobservable`。已验证 399 原视频 100% 采样可找到轮廓，衣物/背景灰度差约 35–50，但阈值跨场景有效性未验证。

## 周期切分

新建独立 `AbdominalVisualSegmenter`，输入 `VisualSignal`，输出 `SegmentationResult(version='abdominal_visual_v1')` 和质量诊断。只在可信信号中处理。用约 1.1 秒中值/均值平滑、峰间最短 3.5 秒、局部显著性门槛（位移相对 L 的 1%，并高于准备段噪声）得到隆起候选。峰两侧需有局部低谷，连续上升与下降、至少 0.6 秒准备和回稳证据；视频边缘缺失基线或回落时拒绝候选。峰宽在局部振幅 80% 以上定义平台区间，提供起止秒、顶点平台和拒绝理由。计数绝不由视频长度或指导节拍推导；第一次准备可从 0.6–1.5 秒的稳定子窗口选取。异常/不可观测结果不应被视为“观察到 0 次”。

实现时优先通过 398/399 曲线核验完整边界，再固定阈值，避免只凭正例调低峰值门槛。首轮只在小样本影子模式记录候选，不把 `Rep` 送现有 `AbdominalCrunchCalculator`；后者的 `abdominal_displacement` 单位为角度，不能给体表位移打分。

## 集成与兼容

`analyze_video.py` 在 `segmentation_mode='shadow'` 且 `action_type='abdominal_crunch'`、短片条件下，在已有 legacy 和 cycle 诊断之后调用视觉模块，使用本地原视频和 `visualization_frames`。包装独立 try/except，视觉提取失败只写 `visual_unavailable_reason`，正式 `formal_result`、`reps`、评分、状态、回调完全保留现状。`_build_segmentation_snapshot` 增加 `visual_version`、`visual_rep_count`、`visual_count_delta`、`visual_quality`、`visual_accepted_cycles`、`visual_rejected_candidates`、`visual_extract_ms` 和 `visual_segment_ms`。沿用 `SegmentationCandidate` 和时间戳映射；其中字段单位明确为 normalized body length。避免序列下标与视频原始帧号混淆。

说明：本轮开始前工作区已有短缩腹 0 次转 `review_required` 及患者文案改动。它们不是视觉影子模式引入的行为，本设计的“不改变”特指新增视觉模块不再改变这些既有逻辑。

正式切换是独立后续门槛：补录不同日期/衣着正负例、复核假阳性与未回稳、设计位移版评分模板、统一患者指导后，才可新增显式视觉正式模式。历史报告仍按原 `segmentation_version` 解释，不回填或悄然改写。

## 异常与测试

- 纯合成单元测试：明暗边界、衣物/背景低对比、缺关键点、遮挡、无视频、单个隆起、两个隆起、静止、只有上升、只有下降、末尾截断；检查不虚构完整次数。
- 原视频本地验证脚本/可跳过集成测试：398→1、399→2；平台分别与 4–6、16–17 秒重叠；0–1.5 秒不形成单独候选。裁切同源片段只作边界回归，不算独立样本。
- 快照契约测试：正式旧计数和评分不变；视觉失败仍完成旧流程；候选时间戳可回看；单次短片视觉开销受控。
- 不提交原视频/截图；测试仅提交合成信号。保留本地原视频诊断记录与运行耗时，质量不达标只显示待复核含义。

实施核验截至本轮：分析服务 60 项测试通过，覆盖完整/截断/半程、轮廓缺失、30fps、准备阶段片头抖动与快照隔离。398/399 原视频像素峰虽已人工和离线脚本核对，但因本机 MediaPipe 无法在无图形 macOS 初始化，尚未完成真实姿态点参与的端到端 1/2 次验收；不得据此启用正式视觉计数。

## 已知风险与后续门槛

边缘阈值依赖上方背景比衣物亮、侧视腹壁外缘清楚；宽松阈值可能误把床单/手臂当腹部。姿态点相对局部坐标可削弱人体平移，但无法完全消除镜头移动和旋转。抽样速度低时峰宽和平台边界精度下降。小样本不能支持自动临床评分；影子结果只供管理员复核。用户已明确要求“继续完成落地”，故本轮按已授权的影子阶段实施，无需再次等待设计确认。

P05 报告页

阶段与结果状态
报告页建议把三阶段和拉取状态全部放到这里独立展示，主页面本体只展示当前实际阶段，避免把策略说明硬塞进页面正文。
阶段 A
纠错期
优先识别问题，不把信息铺得过满
适合刚开始训练或本次问题较集中的患者，重点是把最关键的错误说清楚，并明确下一步怎么改。
只保留 1~2 条关键问题，避免患者被大量术语压住。
优先引导回看指导页，对照正确动作和拍摄要求。
阶段 B
巩固期
先肯定已有进步，再给轻量优化建议
适合动作已经基本成型的患者，页面表达更偏向“做对了什么”与“下一步再稳一点”。
突出较上次进步、稳定性提升和保持时间改善。
只保留 1 条继续优化建议，减少挫败感。
阶段 C
激励期
让患者看到连续训练带来的成果
适合已形成稳定习惯的患者，强调连续训练、满周达标、徽章激励和轻量鼓励文案。
把成长进度、满周完成和徽章获取放到更前面。
建议文案更短、更鼓励，减少重复纠错表达。
报告加载中
轮询等待
展示报告详情拉取中的骨架状态，避免页面突然跳空，也让患者知道系统仍在继续处理。
报告拉取失败
可重试
保留“重新加载”和“继续等待结果”两个动作，避免患者误判为需要重新训练或重新上传。
按钮 1：重新加载当前结果。
按钮 2：继续等待，稍后从历史页或消息中心进入。

# 缩腹视频 398/399：顶点复核与切分落地方案

> 2026-10-12。依据本地 398/399 关键点快照、原视频、当前代码和人工时间标注。原视频已找到并初验腹壁像素运动；两例验证不代表跨机位泛化，也不是临床有效性结论。

## 1. 先统一“顶点”含义

现有程序的 `peak` 是肩中点到髋中点的三维向量相对竖直方向的**角度局部最大值**。本方案的目标顶点已由动作标注者确认为**吸气时腹部向外隆起最高，并维持住的阶段**。两种峰没有必然对应关系。MediaPipe Pose 当前提取的八个点中没有腹部表面点。

人工标注将 399 的准备段定为 0–1.5 秒；第一次动作约 1.5–9 秒，顶点平台 4–6 秒；第二次约 9–21 秒，顶点平台 16–17 秒。398 是约 8.9 秒的第一段动作。最终阶段边界以复看原视频后的标注为准。

当前平滑后角度峰：398 为 1.0 秒；399 为 1.0、14.2、18.2 秒。第一次顶点 4–6 秒内角度总体下降，第二次顶点范围内约 16.9 秒为局部**低点**。因此当前角度峰与人工顶点在定义和时间上均不一致。该角度约 89°，肩髋竖直差接近 0；使用 `abs(dy)` 后，竖直差过零还会形成局部高点。准备段 0–0.6 秒就产生约 0.71° 的角度变化，足以干扰峰值检测。

本方案统一使用“腹部隆起顶点/顶点平台”，避免将腹部隆起解释为腹肌收缩强度。指导内容仍有冲突：标准配置写有“吸气，腹部自然隆起，保持 3 秒”；文字指导写有“自然呼气时向内收紧腹部”。产品上线前须由动作负责人核对教学视频，将步骤、图注、语音和报告用语统一到实际训练动作。现有角度峰不得更名为腹部隆起顶点。

## 2. 最小可行路线

### 第一步：取得原视频并人工复核（已完成初验）

本地 `docs/标准教学视频/缩腹运动_0-9秒.mp4`、`缩腹运动_0-22秒.mp4` 与 398/399 的时长、姿态和前 7.77 秒共同画面吻合，仅用于本地诊断；它们被 Git 忽略，不把患者视频或未经脱敏的截图提交到仓库。人工在同一播放器上标记：准备结束、目标动作开始、顶点平台起止、回落结束；每处允许标成时间区间，不强求单帧精度。同时记录机位、腹壁轮廓是否可见、衣物或手是否遮挡、镜头是否移动。

用时间戳叠加当前角度曲线和人工阶段。保留现有峰值结果作为对照，确认 398/399 的 0 次是哪些候选及门槛造成的。准备阶段允许从 0.6–1.5 秒取稳定子窗口；不能把 0–0.6 秒的角度漂移解释为已开始收缩。

### 第二步：验证腹壁可观测信号

保持现有 10 fps 视频采样。先按肩、髋关键点建立随人体移动的腹部 ROI；对视频帧做前景/人体轮廓提取。在躯干轴中段测量腹壁外缘到躯干参考轴的垂直距离，取多条扫描线的中位数，再除以肩髋距离，得到无量纲体表曲线。同步记录轮廓有效比例、人体/镜头整体位移和遮挡情况；镜头位移需用床面/背景或骨盆参考点校正。目标是体表位移代理值，不能解释成腹肌收缩强度或真实腹部厚度。

候选信号只做离线比较，不预设一定有效：轮廓距离、腹部 ROI 的局部光流、现有肩髋角。每条信号都要画在人工标注时间轴上，检查两次顶点平台是否可分、回落是否可见、准备段是否安静。轮廓不可见、背景与衣物难分、或信号与人工阶段不一致时，记录为“视频证据不足”，不靠降低阈值强行计数。

### 第三步：实现腹部曲线的周期确认

使用经确认的腹壁**向外距离**曲线：准备基线 → 吸气时持续隆起 → 最高处平台 → 呼气时回落 → 回到基线。顶点在这个距离曲线上应为**高位平台**；若图像坐标系的测量方向相反，先统一符号再判断。对每段使用自己的准备/回稳中位数和噪声水平；用高低两个阈值防止平台抖动反复切段。局部回弹只有在已经回稳且再次形成完整隆起、平台、回落时才算下一次。时长是宽松保护，按实际时间戳而非固定帧下标判定；先覆盖约 8–13 秒的两段动作，再由更多样本确定正式范围。

顶点输出为平台时间区间，不强制输出某个像素噪声导致的瞬时极值。首段可以使用 0.6–1.5 秒的稳定准备子窗口；如果准备证据不足，可以产生低置信候选并转人工复核。视频末尾没有可确认回落时不计“完整动作”。节拍提示只能作为搜索窗口先验，不能凭计划节拍自动记一次。

### 第四步：接入报告，但先运行影子模式

在 `PhaseSegmenter` 增加独立缩腹信号和切分版本；任务层把旧峰值、现有闭环、新腹壁方案的候选、起止/顶点区间、拒绝原因和信号质量保存到 `segmentation_snapshot`。保留历史算法与历史报告的版本标记。影子运行只对照，不改变患者正式次数。

腹壁位移为归一化长度，而当前 `AbdominalCrunchCalculator` 的 `abdominal_displacement` 是角度（度）；旧模板、保持时间和评分不能直接复用。单独版本化新特征与模板，在两段视频验证通过前只展示“观察到的完整周期/待复核”，不生成确定性质量分。若视觉证据不足，保留训练记录并提示待复核；只有质量充分且确无周期证据时才输出 0 次。

## 3. 小样本验收与上线门槛

第一轮只用 398、399 做**可观测性验证**：398 应识别第一段一个完整周期；399 应识别两个完整周期；腹壁向外距离的高位平台应分别与人工标注的 4–6 秒、16–17 秒重叠；准备段 0–1.5 秒不得独立计数。再把 399 截成准备段、只有隆起/只有回落、尾部截断等负例，确认不会靠切片时长凑次数。切片来自同一视频，不能算独立样本。

若两段视频的腹壁轮廓可见且曲线与标注吻合，可做小范围影子验证：补录不同日期、不同衣着的 3–5 段完整动作与 3–5 段静止/半程/遮挡负例，逐段人工标记次数和顶点区间。先要求关键正例无漏计、负例无误计，并逐项复核边界；不以总次数碰巧相同作为通过。样本仍少时只向人工提供候选，不自动给确定分数。出现轮廓不可观测或跨衣着失效，应停止视觉自动计数上线，采用引导节拍记录训练、视频留存和人工复核的产品方案。

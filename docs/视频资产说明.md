# 教学与算法验证视频资产说明

> 状态：保留资产。`docs/video/` 和 `docs/标准教学视频/` 当前被 Git 忽略，用于本地教学内容核验、算法回归和人工诊断；文档治理不得删除这些文件。

## 1. 目录职责

| 目录 | 内容 | 当前用途 | Git 策略 |
| --- | --- | --- | --- |
| `docs/标准教学视频/` | 三类动作的标准教学视频及局部片段 | 动作口径核验、算法试验、人工标注与回归 | 被忽略，不提交 |
| `docs/video/` | 教学视频的本地副本/样例片段 | 分析服务的本地样例回退与人工查看 | 被忽略，不提交 |
| `gold_standard_output/` | 从样例分析得到的模板、关键点、报告等文本/JSON 产物 | 模板与算法输出追溯 | 按仓库现状提交 |

## 2. 当前保留边界

- 这些资产不是患者上传视频的替代品，也不应包含未经批准提交到 Git 的患者可识别素材。
- 代码和文档只能引用相对路径、动作类型和用途；不要把视频复制进小程序包或普通产品文档。
- 如需对外分发、跨机器复现或长期留存，应由项目负责人建立受控对象存储或 Git LFS 的来源清单；在完成迁移前，原文件仍保留。
- 新增片段应命名为“动作类型 + 时间范围”，并在同次变更中说明来源、用途、是否含敏感信息和可保留期限。

## 3. 使用前检查

1. 确认文件仅用于本地算法验证或受控教学核验；
2. 确认无患者隐私或未授权的可识别内容；
3. 记录与哪一种动作、哪个算法版本或哪次标注关联；
4. 不在提交代码前通过 `git add -f` 绕过忽略规则。

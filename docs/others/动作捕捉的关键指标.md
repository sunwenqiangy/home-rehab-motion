# 动作捕捉的关键指标

## 一、缩腹运动（Abdominal Draw-in）评估

缩腹运动主要训练**腹横肌**和**核心稳定**。

### 关键动作特征

- 腹部向内收缩
- 躯干基本保持稳定
- 骨盆不明显移动

### 评价指标

| 指标 | 说明 |
|------|------|
| **腹部收缩幅度** | 可用躯干厚度变化或腹部位移表示（静息腹部厚度 − 收缩时腹部厚度） |
| **躯干角度变化（稳定性）** | 角度变化 < 5° 为动作稳定 |
| **保持时间（持续时间）** | 收缩维持时间 |

> 动作捕捉（光学 marker）不能直接测腹横肌收缩，只能测**体表形变（腹壁位移/厚度变化的替代指标）**，所以需要建立**腹部前后位移模型（proxy）**，而不是肌肉本身。

### 核心思路

**腹部收缩幅度 = 腹壁前表面相对躯干参考平面的后移距离**

### 标记点布置

#### 必须标的骨性参考框架（用于稳定坐标系）

- 左右 **ASIS**（髂前上棘）
- 左右 **PSIS**（髂后上棘）（或腰部替代点）
- 用于：定义骨盆平面（避免骨盆动了被误判为腹部收缩）

#### 腹部标记点（核心）

**基础版（可用）：**

| 标记点 | 位置 |
|--------|------|
| **UMB** | 脐点（肚脐）——**最重要** |
| **ABD_U** | 脐上约 5 cm（腹直肌区域） |
| **ABD_L** | 脐下约 5 cm |

**增强版（推荐发文章用）：**

| 标记点 | 位置 |
|--------|------|
| **UMB** | 脐 |
| **ABD_U** | 上腹 |
| **ABD_L** | 下腹 |
| **ABD_LR** | 左侧腹，脐水平外侧 5 cm |
| **ABD_RR** | 右侧腹 |

用于：捕捉整体腹壁收缩（避免局部误差）

#### 躯干稳定参考点（防止代偿）

- 胸骨（sternum）
- T10 或 T12（背部）

## 二、骨盆倾斜运动（Pelvic Tilt）评估

骨盆倾斜是核心康复中常见动作。

### 关键动作特征

- 骨盆前倾 / 后倾
- 脊柱轻微变化
- 下肢基本固定

### 评价指标

| 指标 | 说明 |
|------|------|
| **骨盆前倾角度** | 床面为水平线，髂前上棘为标记点；髂前上棘活动前后位置点的连线与水平线的夹角 |
| **骨盆后倾角度** | 床面为水平线，髂前上棘为标记点；髂前上棘前后变化的连线与水平线的夹角 |
| **骨盆水平偏移** | — |
| **保持时间** | — |

### 测量方法

骨盆倾斜角度通过**三维动作捕捉系统**计算。于受试者骨盆体表放置四个反光标记点：

| 标记点 | 名称 |
|--------|------|
| **LASIS** | 左髂前上棘（left anterior superior iliac spine） |
| **RASIS** | 右髂前上棘（right anterior superior iliac spine） |
| **LPSIS** | 左髂后上棘（left posterior superior iliac spine） |
| **RPSIS** | 右髂后上棘（right posterior superior iliac spine） |

- 以**左右髂前上棘的中点**作为骨盆前方参考点
- 以**左右髂后上棘的中点**作为骨盆后方参考点
- 构建骨盆的前后方向轴

### 计算公式

骨盆前倾角度定义为骨盆前后轴（由 PSIS 中点指向 ASIS 中点的向量）与水平面之间的夹角：

$$
\text{ASIS\_m} = (\text{LASIS} + \text{RASIS}) / 2
$$

$$
\text{PSIS\_m} = (\text{LPSIS} + \text{RPSIS}) / 2
$$

$$
\alpha = \arctan\left(\frac{z_{\text{ASISm}} - z_{\text{PSISm}}}{\sqrt{(x_{\text{ASISm}} - x_{\text{PSISm}})^2 + (y_{\text{ASISm}} - y_{\text{PSISm}})^2}}\right)
$$

其中 α 表示骨盆倾斜角度：

- 当 ASIS 中点**低于** PSIS 中点时（α > 0），定义为**骨盆前倾**
- 当 ASIS 中点**高于** PSIS 中点时（α < 0），定义为**骨盆后倾**

骨盆倾斜角度的变化量通过动作过程中各时间点 α 值相对于初始姿势 α 值的差值进行计算。

## 三、膝关节旋转运动评估

膝关节旋转多用于下肢协调和核心控制训练。

### 关键动作特征

- 膝关节旋转
- 髋部稳定
- 躯干不明显代偿

### 评价指标

| 指标 | 说明 |
|------|------|
| **膝关节旋转角** | 髋-膝-踝关键点计算 |
| **髋部稳定性** | 变化过大视为异常 |
| **动作代偿** | — |
| **保持时间** | — |

### 核心思路

**膝关节旋转角 = 股骨坐标系 vs 胫骨坐标系 的相对旋转（绕纵轴）**

必须：
1. 建立股骨坐标系
2. 建立胫骨坐标系

### 推荐标记点布置（标准做法）

#### 骨盆/髋部（用于稳定性 + 参考）

- ASIS（左右髂前上棘）
- PSIS（左右髂后上棘）或替代点
- 用于：定义骨盆 / 评估髋部是否稳定

#### 股骨（大腿段）——至少 3 个点（构建刚体）

| 标记点 | 名称 |
|--------|------|
| **大转子** | Greater trochanter |
| **股骨外侧髁** | Lateral femoral epicondyle |
| **股骨内侧髁** | Medial femoral epicondyle |

作用：定义股骨长轴，建立股骨坐标系

#### 胫骨（小腿段）

| 标记点 | 名称 |
|--------|------|
| **胫骨粗隆** | Tibial tuberosity |
| **外踝** | Lateral malleolus |
| **内踝** | Medial malleolus |

作用：定义胫骨长轴，建立胫骨坐标系

#### 足部（提高精度，可选但推荐）

- 跟骨（Calcaneus）
- 第 2 跖骨头（或第 1 / 第 5）

### 膝关节旋转角计算步骤

**Step 1：建立两个向量**

- **股骨轴线**：髋（或大转子） → 膝（股骨髁中点）
- **胫骨轴线**：膝（胫骨平台/粗隆） → 踝（踝中点）

**Step 2：建立局部坐标系**

- 股骨坐标系
- 胫骨坐标系
- 计算绕纵轴（Z 轴）的相对旋转角（internal/external rotation）

**Step 3：计算方式（常用两种）**

| 方法 | 说明 |
|------|------|
| **方法 1：欧拉角（推荐）** | 使用 Cardan/Euler angles，提取膝关节内旋/外旋角 |
| **方法 2：投影法（简化）** | 将两段轴线投影到水平面，计算夹角 |

### 常见注意事项

#### ⚠️ 1. 皮肤伪影（STA）

膝关节旋转对误差非常敏感，建议用 **cluster 标记（刚体簇）** 替代单点

#### ⚠️ 2. 必须有内外侧髁

如果只放一个标记点，无法计算旋转，**必须同时放：内侧髁 + 外侧髁**，用于定义膝横轴

#### ⚠️ 3. 髋稳定性评估

可量化指标：

- 骨盆倾斜角（ASIS 高度差）
- 骨盆旋转
- 髋内收/外展角

### 简化版（设备有限时）

**最低配置：**

- 膝内外侧髁
- 内外踝

**可计算：**

- 膝关节横轴 + 胫骨轴
- 旋转角

> ⚠️ 精度会下降

## 四、综合评估要点

| 动作 | 核心评估指标 | 关键注意事项 |
|------|-------------|-------------|
| 缩腹运动 | 腹部收缩幅度、躯干稳定性、保持时间 | 光学 marker 只测体表位移，需建立 proxy 模型 |
| 骨盆倾斜 | 前/后倾角度、水平偏移、保持时间 | 使用 ASIS/PSIS 四点构建骨盆坐标系 |
| 膝关节旋转 | 旋转角、髋部稳定性、代偿情况、保持时间 | 必须有内外侧髁标记点；注意皮肤伪影 |

### 关键评估方法特征

- ✅ **准确性**：角度计算准确
- ✅ **稳定性**：动作稳定可重复
- ✅ **动作控制**：无明显代偿动作
- ✅ **关联方法**：适用于协调运动评估，需多传感器协同和核心控制闭环

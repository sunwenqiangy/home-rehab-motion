🧮 逐步计算逻辑
从原始坐标到最终指标的完整链路
1
提取肩部中点 & 髋部中点
MediaPipe 给出每帧 x,y∈[0,1] 的归一化坐标，先计算两侧的中点
# 肩中点 shoulder_mid_x = (kps[11].x + kps[12].x) / 2 shoulder_mid_y = (kps[11].y + kps[12].y) / 2 # 髋中点 hip_mid_x = (kps[23].x + kps[24].x) / 2 hip_mid_y = (kps[23].y + kps[24].y) / 2
2
计算躯干角度（驱动切分用）
肩-髋连线与垂直轴的夹角，侧面拍摄时腹肌收缩会让脊柱微微弯曲，角度产生变化
# 向量：从髋指向肩 dx = shoulder_mid_x - hip_mid_x dy = shoulder_mid_y - hip_mid_y # y轴向下为正 # 与垂直轴（0,-1）的夹角 trunk_angle = degrees(arctan2(dx, -(dy + 1e-8))) # 单位：度。收缩时角度增大 → 信号出现波峰
📍 切分信号 = trunk_angle 时间序列，找极大值 → 每个波峰 = 一个完整收缩周期
3
计算骨盆偏移（稳定性指标）
正确缩腹时骨盆应保持稳定不偏移，偏移量越大说明代偿越多
# 左右髋关节 X 坐标差（代理骨盆横向偏移） pelvis_shift = |mean(kps[23].x) - mean(kps[24].x)| × 100 # 单位：% 画面宽度。越小越稳定
4
计算躯干角度变化量（代偿指标）
整个周期内躯干角度的最大变化量，越小说明核心稳定、无代偿
# 周期内最大值 - 最小值 trunk_angle_change = max(trunk_angle_arr) - min(trunk_angle_arr) # 金标准：mean=28.59°, std=39.66（来自教学视频 n=7 周期）
5
识别「保持阶段」→ hold_duration
用速度方差法：当髋宽变化速度连续低于阈值，判定为在顶峰保持
# 计算逐帧速度 vel = diff(trunk_angle_arr) # 帧间差 thr = std(vel) × 0.5 # 阈值 = 半个标准差 in_hold = [v ≤ thr for v in abs(vel)] hold_duration = count(in_hold) / sample_fps # 单位：秒。越长越好。金标准 mean=1.45s

🎯 阈值判定规则

📌 这块是干嘛的？
系统对患者每一次动作周期计算出若干指标值（如倒膝幅度、骨盆偏移量），
然后拿这些值和"标准答案"对比，判断动作是 ✅ 正常、⚠️ 偏差 还是 ❌ 异常。
📐 值从哪来？
右侧列出的 mean（均值） 和 std（标准差） 来自
金标准——康复治疗师拍的教学视频，由系统自动提取多个动作周期后统计得出（2026-06-25）。
🔍 怎么判断？
以均值为中心，±2σ 以内 → 正常；±2~3σ → 偏差（轻微超标）；超出 ±3σ → 异常（需关注）。
左侧示例图中蓝色为正常区，黄色为偏差区，红点为真实样本散布。

三级判定：正常 / 偏差 / 异常，基于金标准 ±2σ / ±3σ 区间

📏 三级判定逻辑（knee_y_excursion 倒膝幅度 示例）
gold_mean=11.32, gold_std=9.31 valid_range = [mean-2σ, mean+2σ] = [0, 48.55] warning_range = [mean-3σ, mean+3σ] if val in valid_range: → ✅ 正常 elif val in warning_range: → ⚠️ 偏差 else: → ❌ 异常

def param_score(val, mean, std, direction): z = (val - mean) / std if direction == 'smaller_better': raw = 100 - max(0,z)*15 elif direction == 'larger_better': raw = 100 + min(0,z)*15 else: raw = 100 - abs(z)*15 return clip(raw, 0, 100) accuracy = 0.40×trunk_s + 0.60×disp_s stability = 0.50×pelvis_s + 0.50×trunk_s total = 0.35×acc+0.25×stab+0.20×ctrl+0.20×pers total = clip(total × conf_factor, 0, 100)

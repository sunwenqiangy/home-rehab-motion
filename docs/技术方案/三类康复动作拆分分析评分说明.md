# 三类康复动作拆分、分析与评分说明

> 适用动作：缩腹运动（`abdominal_crunch`）、骨盆倾斜（`pelvic_tilt`）、膝关节旋转（`knee_rotation`）  
> 对应实现：`services/analysis-service/app/core/`  
> 本文描述的是当前线上分析链路的实际逻辑，用于产品、算法、临床复核和模板标定的共同理解。

---

## 1. 一句话概览

系统并不是直接按视频时长或“看起来动了一下”计数，而是对每个视频依次执行：

1. **提取姿态关键点**：使用肩、髋、膝等关键点建立身体几何关系；
2. **质量与预处理**：剔除低置信度点、短缺失插值、轨迹平滑、按肩宽缩放、按初始髋部位置平移；
3. **动作切分**：不同动作使用不同的驱动信号与完整周期定义；
4. **单周期特征计算**：为每个识别到的周期计算幅度、速度、保持、稳定性/对称性等指标；
5. **金标准比对**：优先采用数据库中启用的最新模板，缺失项再回退默认模板；
6. **四维评分与建议**：将特征映射到准确性、稳定性、控制性、保持时长四个维度，并输出总分、等级和训练建议。

```text
原始视频
  → 姿态关键点
  → 质量门禁与预处理
  → 动作专属信号
  → 周期切分（Rep 1, Rep 2, ...）
  → 每个周期的特征
  → 金标准比较（normal / warning / invalid）
  → 四维加权评分、视频汇总与建议
```

系统的一个 **Rep** 表示一次可被认可的完整训练周期，而不是一个局部峰、一次左转或一个单帧姿势变化。

## 2. 统一基础链路

### 2.1 使用的关键点

| 关键点 | 主要用途 |
| --- | --- |
| 左/右肩 | 计算肩中点、躯干方向、身体尺度 |
| 左/右髋 | 计算髋中点、躯干—骨盆关系、骨盆位移 |
| 左/右膝 | 计算膝部旋转幅度、对称性、旋转节奏 |
| 左/右踝 | 骨架完整性与可视化辅助 |

其中，肩中点与髋中点为：

\[
S = \frac{S_L + S_R}{2}, \qquad H = \frac{H_L + H_R}{2}
\]

### 2.2 视频质量与预处理

在切分之前，所有动作共享以下安全门禁与处理步骤。

| 阶段 | 当前规则 | 目的 |
| --- | --- | --- |
| 关键点置信度过滤 | `visibility < 0.5` 的关键点坐标标记为缺失 | 不让低可信姿态直接驱动动作判断 |
| 必需躯干点校验 | 躯干关键点有效帧占比至少 70% | 防止长期遮挡、离镜时虚构运动轨迹 |
| 缺失补偿 | 仅对不超过 10 帧的连续缺失做线性插值 | 短暂漏检可补偿，长时间遮挡不伪造 |
| 轨迹平滑 | 对 X、Y 轨迹做 Savitzky–Golay 平滑（默认窗口 7，三阶） | 降低单帧抖动造成的假峰/假谷 |
| 尺度归一化 | 按每帧肩宽归一化 | 减少拍摄距离、体型差异造成的幅度差 |
| 原点归一化 | 用第一个有效髋中点作为坐标原点 | 降低整体入镜、镜头平移对位移指标的干扰 |
| 切分信号平滑 | 边缘复制填充后移动平均 | 避免旧式零填充在视频首尾制造假峰/假谷 |

### 2.3 通用有效性限制

切分时先检查动作专属信号的稳健摆幅：视频长度不少于 20 帧时取 5%–95% 分位数差，否则取全极差。

| 动作 | 驱动信号最小摆幅 | 不满足时的含义 |
| --- | ---: | --- |
| 缩腹运动 | 0.5° | 未观察到足够的躯干屈曲变化 |
| 骨盆倾斜 | 2.0° | 未观察到足够的矢状面后倾变化 |
| 膝关节旋转 | 15.0° | 未观察到足够的髋—膝连线变化 |

不满足时不应把结果解释为“训练不佳”，而会提示视频动作与所选类型可能不匹配。

完成切分后还会做数量合理性校验：缩腹 3–25 次、骨盆倾斜 3–30 次、膝关节旋转 4–20 次。该校验是宽松的类型一致性保护，不是处方次数要求。

## 3. 缩腹运动（`abdominal_crunch`）

### 3.1 动作语义与建议机位

缩腹的核心是收紧腹部、使躯干发生屈曲。建议侧方或略侧方拍摄，使肩、髋和身体深度变化尽量可见。

二维画面中缩腹可能主要发生在镜头深度方向；因此不能仅依赖二维肩髋夹角。

### 3.2 驱动信号

对每帧计算肩中点到髋中点的三维向量：

\[
\vec v = S - H = (dx, dy, dz)
\]

缩腹屈曲信号为该向量相对竖直方向的夹角：

\[
\theta_{flex} = \operatorname{atan2}(\sqrt{dx^2 + dz^2}, |dy|)
\]

- 单位：度（°）；
- `dx` 表示画面横向变化，`dz` 保留姿态模型提供的深度变化；
- 收缩越明显，通常屈曲信号越大。

### 3.3 周期拆分

#### 周期定义

缩腹的回位谷值在实际视频中常较浅，容易被呼吸、衣物遮挡和姿态抖动淹没。因此当前逻辑以**独立收缩峰**为中心切分：

```text
前一收缩峰 —— 当前收缩峰 —— 后一收缩峰
       │             │             │
     周期边界       收缩顶点       周期边界
   （相邻峰中点）                  （相邻峰中点）
```

- 当前峰前后相邻峰的中点作为周期边界；
- 第一个、最后一个峰分别可使用视频开头、结尾作为边界；
- 每个周期要求 4–18 秒；
- 周期内以 20% 分位数作为静息基线，主峰相对此基线的摆幅需达到动态阈值；
- 峰间最小间隔为 3.5 秒，以合并同一次收缩内的局部姿态抖动；峰显著性随信号标准差和稳健摆幅动态调整。

若严格切分没有结果，系统会以更保守的峰/谷参数回退切分，再过滤过短周期并尝试在过长周期内按内部谷值拆分。回退的目标是避免“完全无结果”，并不改变单个周期的基本语义。

### 3.4 单周期分析参数

| 参数 | 计算方式 | 临床/动作含义 | 评分维度 |
| --- | --- | --- | --- |
| `abdominal_displacement` | 屈曲信号 90% 分位数 − 10% 分位数 | 腹部收缩/躯干屈曲的有效幅度 | 准确性 |
| `displacement_velocity` | 起始至主峰阶段的帧间绝对角速度中位数 | 收缩过程的节奏控制 | 控制性 |
| `hold_duration` | 主峰周围连续高于“基线 + 85%有效幅度”的时间 | 收紧终点的连续保持 | 保持时长 |
| `trunk_angle_change` | 周期内躯干二维向量相对首帧的最大夹角 | 躯干姿态变化/潜在代偿 | 稳定性 |

> `hold_duration` 只统计主峰附近连续的平台，不再以整个周期时长比例估计。

## 4. 骨盆倾斜（`pelvic_tilt`）

### 4.1 动作语义与建议机位

当前业务语义是：患者平躺，吸气时轻轻收紧下腹，使腰背更贴近垫面，形成后倾顶点；呼气后回到中立位。一次完整训练应为：

```text
稳定中立位 → 后倾/收紧顶点 → 回到稳定中立位
```

建议采用**正侧方机位**（即侧方拍摄），保证肩、髋的前后倾变化可见。

> 关键更新：骨盆倾斜不再以“左右髋连线是否倾斜”作为主信号。左右髋连线更容易反映正面画面的左右歪斜，而不能代表“腰背贴近垫面”的矢状面后倾。

### 4.2 驱动信号

使用髋中点指向肩中点的二维向量相对竖直方向的**有符号矢状面倾角**：

\[
\theta_{pelvis} = \operatorname{atan2}(S_x - H_x, H_y - S_y)
\]

- 单位：度（°）；
- 正负方向与拍摄朝向有关，算法以相对中立位的偏离量/摆幅判断，不把固定正负号当成动作成败；
- 对缺失点以有效信号插值（边界处延续最近有效值），避免用 0° 填充制造假的中立谷值。

### 4.3 周期拆分：状态机闭环

#### 周期定义

骨盆倾斜采用最严格的“中立—顶点—中立”闭环：

```text
稳定中立谷值       后倾顶点             稳定中立谷值
     │                 │                       │
     └──── execute ────┼──── hold/return ──────┘
                 一个完整 Rep
```

当前实现步骤：

1. 在平滑后的矢状面信号中寻找峰和谷；
2. 只有谷值附近连续稳定约 0.7 秒才可作为“中立边界”；
3. 相邻两个稳定中立边界之间，选相对两端中立位摆幅最大的峰作为后倾顶点；
4. 周期时长必须在 10–30 秒；
5. 顶点相对起始、结束中立位的两侧幅度都必须超过动态幅度阈值；
6. 只有满足上述条件的完整闭环才计为一次。

动态幅度阈值取以下三者最大值：0.5°、信号标准差的 30%、整个信号极差的 10%。中立稳定阈值取 0.15°、标准差的 12%、极差的 2.5% 中的最大值。

#### 视频开头立即开始时如何处理

峰/谷检测通常不会返回第 0 帧。为避免患者一开录就完成第一个动作时漏计，系统会在以下条件满足时将第 0 帧补为起始中立边界：

- 开头信号与第一个稳定回正谷值接近；且
- 开头到首峰的变化方向足够单调（至少 70% 的帧间变化方向一致），或开头窗口本身稳定。

这让“开录后立即开始、之后完整回正”的首个周期被纳入统计；如果开头已经处于动作中途，则不会错误补入。

### 4.4 单周期分析参数

| 参数 | 计算方式 | 临床/动作含义 | 评分维度 |
| --- | --- | --- | --- |
| `pelvic_tilt_delta` | 矢状面倾角 90% 分位数 − 10% 分位数 | 后倾动作的稳健有效摆幅 | 准确性 |
| `pelvis_shift` | 髋中点 X 相对周期前 3 帧均值的最大绝对偏移 × 100 | 骨盆横向移位/跑偏 | 稳定性 |
| `trunk_angle_change` | 后倾顶点附近局部窗口的倾角 90%–10% 分位数差 | 到达顶点后的额外晃动，不把主后倾本身判为代偿 | 稳定性 |
| `hold_duration` | 后倾顶点两侧连续保持“相对中位基线偏离 ≥ 顶点偏离的 85%”的时长 | 后倾顶点的连续保持 | 保持时长 |

这里有两个重要边界：

- `pelvic_tilt_delta`、保持时长、顶点晃动都使用同一矢状面信号，防止“切分用一个信号、评分用另一个信号”；
- 主后倾幅度是完成动作的必要部分，因此不会直接作为躯干代偿。`trunk_angle_change` 只观察顶点附近的额外不稳定。

### 4.5 当前模板状态

默认骨盆倾斜模板仍保留旧基准：摆幅均值 10°、标准差 2.5°；保持均值 5 秒、标准差 2 秒。由于驱动信号已经切换到矢状面倾角，**下一步需要用侧方标准教学视频和已审核样本重新标定这两个特征及其阈值**。在新模板发布前，数据库中的启用模板可以覆盖默认值。

## 5. 膝关节旋转（`knee_rotation`）

### 5.1 动作语义与建议机位

一次完整膝关节旋转通常包含：屈膝准备 → 向一侧旋转 → 回正 → 向另一侧旋转 → 再回正。

因此，左右方向各一次不是两个 Rep；一个包含双向旋转并回正的往返才是一个完整 Rep。建议正面或略高的视角，完整展示双髋、双膝和双踝。

### 5.2 驱动信号

切分使用左髋到左膝连线的方向角：

\[
\theta_{knee} = \operatorname{atan2}(K_{L,y} - H_{L,y}, K_{L,x} - H_{L,x})
\]

该角度会随屈膝和旋转形成明显的大周期变化，用于稳定地定位整次动作的主旋转峰；这比只看某个 Y 坐标更不容易把左旋、右旋分别计数。

### 5.3 周期拆分：大谷—主峰—大谷

```text
动作间大谷     主旋转峰                  动作间大谷
    │              │                         │
    └── 屈膝、左/右旋与回正的完整往返 ────────┘
```

当前规则：

1. 主峰最小间隔为 18 秒，优先让每次完整动作只保留一个代表峰；
2. 谷值检测使用 20 秒最小间隔，跳过动作内部“左旋回正到右旋”的小谷，只保留动作之间的大谷；
3. 以某个主峰前后的最近大谷作为周期边界；首尾缺少大谷时可向峰前/后各延展约 15 秒形成候选边界；
4. 周期时长必须在 20–45 秒；
5. 主峰相对至少一侧边界的幅度须达到动态阈值（1°、标准差的 20%、全局极差的 5% 三者取最大）。

若严格切分没有结果，会放宽为峰值切分（峰间最小距离 10 秒），用于尽量输出可复核的候选周期。

### 5.4 单周期分析参数

| 参数 | 计算方式 | 临床/动作含义 | 评分维度 |
| --- | --- | --- | --- |
| `knee_rotation_angle` | 双膝中点 X 相对前 3 帧休息位的最大**单向**偏移 × 100 | 单侧最大旋转幅度 | 准确性 |
| `knee_symmetry` | 左、右膝 X 轨迹极差的较小值 ÷ 较大值 | 左右两侧旋转幅度是否均衡，1 为最对称 | 控制性 |
| `rotation_velocity` | 双膝中点 Y 相对休息位信号的平均绝对帧间速度 × fps × 100 | 旋转过程的节奏 | 控制性 |
| `trunk_angle_change` | 躯干二维向量相对周期首帧的最大夹角 | 上身是否随旋转明显代偿 | 稳定性 |

`knee_rotation_angle` 特别采用“相对休息位的最大单向偏移”，而不是周期内 X 轴 max–min。因为完整周期包含左右两个方向，直接取极差会把双向幅度相加，造成长周期数值系统性偏大。

## 6. 三个动作的切分方式对比

| 动作 | 主要驱动信号 | 一个完整 Rep | 典型周期边界 | 时长约束 | 为什么这样设计 |
| --- | --- | --- | --- | ---: | --- |
| 缩腹运动 | 肩—髋三维屈曲角 | 一次独立收缩及其前后过渡 | 相邻收缩峰的中点；首尾可用视频边界 | 4–18 秒 | 回位谷常很浅，强制谷—峰—谷会合并真实收缩 |
| 骨盆倾斜 | 肩—髋有符号矢状面倾角 | 稳定中立 → 后倾顶点 → 稳定中立 | 两个稳定中立谷值 | 10–30 秒 | 必须确认回正，避免准备姿势、半程和尾部未回正被计数 |
| 膝关节旋转 | 左髋—左膝连线方向角 | 左右双向旋转并回正 | 动作间大谷—主峰—动作间大谷 | 20–45 秒 | 跳过动作内部小谷，避免将左旋、右旋拆成两次 |

## 7. 评分机制

### 7.1 模板来源与覆盖优先级

每个周期的特征会与对应动作的金标准参数比对。来源优先级为：

```text
本次分析请求携带的 threshold_config
        ＞ 数据库中启用的最新动作模板 threshold_config
        ＞ 默认阈值

数据库中启用的最新动作模板 reference_stats
        ＞ 代码内 DEFAULT_TEMPLATES 默认统计值
```

这意味着：算法负责稳定地产生特征，参考值和医学阈值可以通过版本化模板调整，不需要为每次临床标定直接修改切分代码。

### 7.2 单特征标签

每项特征输出以下标签之一：

| 标签 | 含义 |
| --- | --- |
| `normal` | 位于正常区间 |
| `warning` | 有偏差，需要注意或调整 |
| `invalid` | 明显不符合有效范围，该周期不计为有效训练 |
| `review_required` | 模板/数值不完整，无法自动可靠评分，需要人工复核 |

支持三种评分方向：

- **双侧比较（默认）**：偏离参考均值过大，可能过低或过高；
- **上限型（`upper_bound`）**：越小越好，适用于骨盆横移、躯干额外晃动等代偿指标；
- **下限型（`lower_bound`）**：越大越好，适用于只关心是否达到最低幅度/保持要求的指标。

如果模板为历史模板且没有明确区间，系统使用与均值的标准差偏离判定：正常通常要求偏离小于 1.5σ，警告上限为 2.5σ。新版模板提供 `valid_range` 与 `warning_range` 时，模板区间优先。

### 7.3 特征到四维评分的映射

| 动作 | 准确性（40%） | 稳定性（25%） | 控制性（20%） | 保持时长（15%） |
| --- | --- | --- | --- | --- |
| 缩腹 | 腹部有效收缩幅度 | 躯干角度变化 | 收缩速度 | 顶点保持 |
| 骨盆倾斜 | 矢状面后倾摆幅 | 骨盆横移 + 顶点额外晃动 | 当前无独立指标 | 顶点保持 |
| 膝关节旋转 | 单向旋转幅度 | 躯干代偿 | 左右对称性 + 旋转速度 | 当前无独立指标 |

当某个动作缺少某一维度的独立特征时，系统会在**已有维度间重新归一化权重**，而不会把缺失维度直接当 0 分。例如骨盆倾斜不提供独立控制性特征，膝关节旋转不提供独立保持时长特征。

### 7.4 从标签到分数

对每个特征先按偏差标签生成分数：

| 标签 | 单特征分数规则 |
| --- | --- |
| `normal` | `max(85, 100 − 偏差σ × 5)` |
| `warning` | `max(60, 80 − 偏差σ × 10)` |
| `invalid` | `max(0, 50 − 偏差σ × 10)` |

同一维度包含多个特征时先取平均，再按可用维度重新归一化加权：

\[
\text{总分} = \sum_{d \in \text{可用维度}}
  \text{维度分}_d \times
  \frac{w_d}{\sum w_{\text{可用维度}}}
\]

默认权重：准确性 40%、稳定性 25%、控制性 20%、保持时长 15%。

总分等级：

| 分数 | 等级 |
| ---: | --- |
| ≥ 90 | 优秀 |
| 75–<90 | 合格 |
| 60–<75 | 需改进 |
| <60 | 无效 |

只要周期内存在 `invalid` 特征，`valid_flag` 即为否；存在 `review_required` 时该周期总分为 0，等级为“待复核”。

### 7.5 视频级汇总与建议

视频级结果对各 Rep 的四维分、总分、保持时长取平均，并统计总次数与有效次数。系统会根据出现 `warning`/`invalid` 的特征生成患者端和医护端建议，例如：

- 骨盆横移偏高：提示尽量保持骨盆稳定；
- 顶点保持不足：提示在目标位置多停留；
- 左右旋转不均衡：提示两侧保持相近幅度；
- 躯干晃动偏高：提示收紧核心、减少代偿。

若模板不完整、视频置信度非高或视频质量非通过，结果会附带人工复核提示。

## 8. 常见现象与判读边界

| 现象 | 可能原因 | 当前系统处理 |
| --- | --- | --- |
| 骨盆倾斜首个周期漏计 | 开录即开始，首帧未被峰谷检测作为谷值返回 | 检查开头是否接近回正基线且动作方向单调，满足时补第 0 帧边界 |
| 骨盆倾斜尾部不计数 | 末次动作没有回到稳定中立位 | 不计数，这是完整闭环要求 |
| 骨盆倾斜被切成多次 | 顶点/中立处有抖动 | 要求稳定中立边界、最短 10 秒周期和双侧幅度校验 |
| 缩腹次数偏少 | 谷值浅、呼吸噪声淹没回位谷 | 以收缩峰与相邻峰中点切分，不强制谷值 |
| 膝关节旋转被算成两次 | 左右方向之间存在内部回正小谷 | 使用 20 秒间隔的大谷，跳过内部小谷 |
| 首尾出现假峰 | 平滑时边缘补零造成突变 | 使用边缘复制填充，不用零填充 |
| 分数与周期切分不一致 | 切分和评分使用不同身体信号 | 骨盆倾斜已统一为矢状面倾角；其他动作也按各自驱动语义计算主要幅度 |
| 周期分数很低但动作看似完整 | 金标准模板仍基于旧信号、样本不足或临床阈值过严 | 优先检查模板版本与特征单位，再按审核样本重标定 |

## 9. 模板标定建议

为了保证“识别对了”之后“评分也合理”，模板标定应与当前特征定义一一对应：

1. 每个动作收集足够数量、拍摄机位合格、由专业人员审核的标准视频；
2. 先人工确认每个 Rep 的起止与临床动作是否一致；
3. 导出每个 Rep 的当前特征值，按动作、拍摄视角、患者能力分层查看分布；
4. 对幅度/速度/保持等双侧指标确定均值、标准差或正常/警告区间；
5. 对位移与晃动等代偿指标使用上限型阈值；
6. 以 `standard_action_template` 新版本发布 `reference_stats` 与 `threshold_config`；
7. 用独立验证集检查“优秀、合格、需改进、无效”与临床复核的一致性，再启用模板。

骨盆倾斜需优先完成这一步：其核心信号已从旧的左右髋连线切换到侧方矢状面倾角，默认模板应随之重建。

## 11. 当前结论

- 三种动作已经使用**不同的运动学信号和周期语义**，不再用同一种简单峰值策略处理；
- 骨盆倾斜当前已统一为“侧方矢状面后倾”语义，并使用完整闭环切分，重点避免首尾误计、准备姿势误计和顶点抖动重复计数；
- 缩腹重点解决深度方向收缩与浅谷问题；膝关节旋转重点保证左右双向往返仅计为一次；
- 评分结果是否符合临床预期，除算法特征本身外，强依赖于与当前特征同语义、同单位的版本化金标准模板；
- 骨盆倾斜的新信号体系已经完成切分与特征一致性改造，后续应优先根据侧方标准样本完成模板与阈值重标定。

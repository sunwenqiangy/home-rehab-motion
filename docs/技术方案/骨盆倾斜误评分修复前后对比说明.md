# 骨盆倾斜误评分修复前后对比说明

> 目的：解释为什么“缩腹运动视频选择骨盆倾斜模式”曾得到高分，以及本次修复后系统会如何处理。  
> 适用范围：缩腹运动、骨盆倾斜、膝关节旋转的视频切分、特征计算、模板比对与评分。  
> 状态：待随本次代码、数据库迁移及模板版本一并发布。

---

## 1. 先说结论

此前，缩腹视频误选“骨盆倾斜”时，系统可能把姿态关键点的小幅波动当作骨盆活动，并且即使核心动作幅度不够，其他评分项也能把总分拉高，所以会出现 96 分甚至 100 分。

修复后有两道保护：

1. **先判断是不是完整骨盆倾斜动作**：必须看到“回到中立位 → 后倾 → 再回到中立位”的完整过程；
2. **再判断骨盆活动幅度是否足够**：用于评分的骨盆活动角度小于 2.5° 时，标记为无效；只要核心幅度无效，视频总分最高只能是 40 分。

因此，缩腹误选骨盆倾斜时，不会再因为稳定性、速度或保持时间看起来正常而获得高分；而真实、幅度足够的骨盆倾斜视频仍可正常获得高分。

---

## 2. 容易混淆的一点：找动作和给分不是同一个指标

骨盆倾斜分析使用两类身体变化，它们职责不同：

| 目的 | 使用的信号 | 用通俗的话说 |
| --- | --- | --- |
| **切分动作次数** | 肩中点到髋中点的矢状面倾角 | 看上半身和骨盆是否完成了“后倾再回正”的完整过程 |
| **判断骨盆活动幅度、给准确性分** | 画面内左右髋连线的角度极差 | 看两侧髋部的姿态是否真的发生了足够变化 |
| **判断顶点是否稳定、保持多久** | 上述矢状面倾角 | 看到达后倾顶点后有没有稳定停住，而不是只有一闪而过 |

这意味着：

- 仅仅看到躯干前后移动，并不等于骨盆活动幅度合格；
- 仅仅左右髋关键点抖动，也不能被当成一次完整骨盆倾斜；
- 必须同时通过“动作闭环识别”和“核心活动幅度判定”，才能获得高分。

## 3. 修复前后，用户能感受到什么差异

| 场景 | 修复前可能发生的情况 | 修复后预期情况 |
| --- | --- | --- |
| 缩腹视频选成骨盆倾斜 | 髋部关键点小幅抖动被当作有效活动，可能高分 | 核心幅度低于门槛，判为无效，总分最多 40 分 |
| 只做了半程骨盆后倾 | 可能按局部峰值算作一次动作 | 没有回到稳定中立位，不计为完整动作 |
| 录制开头调整姿势 | 首尾平滑产生的假峰可能被计数 | 使用边缘复制平滑，不因补零产生假动作 |
| 真实骨盆倾斜，幅度充分 | 旧/新逻辑都应识别，但旧阈值和切分可能不稳定 | 完整闭环会被识别；幅度 ≥3.0° 时准确性判为正常 |
| 真实骨盆倾斜，但幅度偏小 | 有时高分、有时低分，解释性不足 | 2.5°–3.0° 为“需注意”；<2.5° 为无效 |
| 模板或阈值更新后回看老视频 | 无法确认当时依据哪版模板打分 | 老结果标记为 `legacy_unknown`；重新分析后自动补齐模板信息 |

## 4. 核心规则：从“容易被噪声通过”变为“幅度不足不能高分”

### 4.1 骨盆幅度门槛

当前骨盆倾斜核心幅度 `pelvic_tilt_delta` 的规则如下：

| 测得的活动幅度 | 结论 | 对用户结果的影响 |
| ---: | --- | --- |
| ≥ 3.0° | 正常 | 准确性项正常参与评分 |
| 2.5°–<3.0° | 需注意 | 说明完成了动作但幅度偏小，会拉低准确性分 |
| < 2.5° | 无效 | 说明没有观察到足够的骨盆活动，触发总分上限 40 分 |

本次标定样本中：

- 缩腹视频误选骨盆倾斜时，左右髋连线的变化约为 **1.38°–2.18°**；
- 真实骨盆倾斜样本约为 **4.79°–20.83°**；
- 因此把“警告下限”设为 2.5°、“正常下限”设为 3.0°，在两类样本之间留出了缓冲区。

> 这些数值是当前标定样本得出的运行阈值，不代表临床通用处方标准。后续新增患者样本、不同机位或不同身体能力样本时，应按版本重新验证。

### 4.2 总分限幅

骨盆倾斜的核心幅度属于“准确性”维度。只要该维度被判为 `invalid`：

```text
准确性核心幅度无效
  → 本次动作不能算作正确完成
  → 即使稳定性、控制性、保持时间都不错
  → 总分仍不允许超过 40 分
```

这条规则专门解决了“动作类型不对，但其他维度恰好都很好”导致的虚高分问题。

## 5. 切分逻辑的主要变化

### 5.1 骨盆倾斜：必须形成完整闭环

**旧方式**：主要寻找局部“谷值—峰值—谷值”，识别失败时还会退回到更宽松的按峰计数。

**新方式**：只接受以下完整过程：

```text
稳定中立位
  → 后倾达到顶点
  → 回到稳定中立位
```

新规则还会：

- 周期少于 10 秒时不计为独立训练动作，减少把呼吸、调整和抖动当成训练次数的情况；
- 峰值前、后都需要有足够变化，不接受只有单边变化的“半程动作”；
- 不再退回到宽松的峰值切分，避免严格识别失败后又把噪声补算成动作；
- 视频开始或结束处只有在满足“已回到中立且稳定”的条件下才补边界，避免漏掉真正完整的首尾动作。

### 5.2 缩腹：更能识别侧面和深度方向的收缩

缩腹动作由二维躯干角改为三维屈曲角：除了画面内左右变化，也能感知镜头深度方向的身体变化。

这会带来两个效果：

- 对侧面拍摄的正常缩腹更友好，减少多个收缩动作被合并为一次；
- 缩腹本身的躯干变化更容易被正确识别，但不会因此直接获得骨盆倾斜的核心幅度分，因为两类动作的评分指标仍然分开。

### 5.3 平滑边缘：不再人为制造首尾假动作

旧的平滑方式会在视频首尾补 0，可能把正常姿势突然变成很大的角度落差。

新的方式复制首尾真实姿势进行平滑：

```text
旧：真实姿势 → 人为补 0 → 可能产生假峰/假谷
新：真实姿势 → 复制边缘姿势 → 保持姿势连续
```

## 6. 评分规则的主要变化

### 6.1 以前的问题：所有指标用同一种“双侧距离”判断

旧逻辑主要看“测得值离模板均值有多远”。这对不同类型指标并不总是合理：

- 动作幅度、保持时间通常是**越大越充分**，不应因为大于平均值而被当成错误；
- 横移、躯干晃动通常是**越小越稳定**，不应因为小于平均值而扣分。

### 6.2 现在按指标方向评分

| 指标类型 | 当前规则 | 示例 |
| --- | --- | --- |
| 越大越好 | 只检查下限 | 骨盆活动幅度、动作保持时间 |
| 越小越好 | 只检查上限 | 骨盆横移、躯干额外晃动 |
| 有合理区间 | 同时检查上下限 | 需要维持适中速度的指标 |

好处是评分更符合直觉：动作充分不会因“做得比均值大”被扣分；稳定性更好也不会因“晃动太小”被扣分。

## 7. 模板版本留痕和历史结果补起

### 7.1 新增记录内容

每次新分析或重新分析完成后，视频评分结果会保存：

| 字段 | 含义 |
| --- | --- |
| `template_id` | 实际使用的金标准模板记录 ID |
| `template_version` | 实际使用的模板版本号 |
| `threshold_snapshot` | 本次判定使用的阈值快照 |

管理端视频详情会返回 `templateId`、`templateVersion`，便于排查“为什么这条视频是这个分数”。

### 7.2 已有历史结果如何处理

旧结果产生时没有保存模板来源，不能安全地根据当前启用模板倒推出历史依据。因此迁移后会：

```text
旧结果
  → template_version = legacy_unknown
  → 不伪造 template_id 或阈值快照
  → 管理员重新分析原视频
  → 用当前实际模板重新计算并自动补齐来源信息
```

管理员现在可以对 `completed`、`failed`、`quality_insufficient`、`review_required` 状态的视频重新发起分析。对于需要回溯的旧视频，应通过重新分析补起，而不是仅修改数据库字段。

## 8. 发布与验证建议

### 发布前必须执行

1. 执行 Prisma migration：`20260801100000_add_evaluation_template_provenance`；
2. 确认数据库启用的骨盆倾斜模板包含：
   - `pelvic_tilt_delta.scoring_mode = lower_bound`
   - `normal_min = 3.0`
   - `warning_min = 2.5`
3. 同步发布 `main-service` 与 `analysis-service`：两端共同支持模板留痕回调；
4. 对历史重点样本使用管理端“重新分析”，补齐模板来源并验证新结果。

### 验证样本建议

至少准备以下几类视频，并由人工确认真实动作类型：

| 样本 | 选择的分析模式 | 预期 |
| --- | --- | --- |
| 标准缩腹 | 骨盆倾斜（故意误选） | 不应高分；核心幅度 <2.5° 时总分 ≤40 |
| 标准骨盆倾斜 | 骨盆倾斜 | 应识别完整次数；幅度 ≥3.0° 时准确性正常 |
| 小幅度骨盆倾斜 | 骨盆倾斜 | 应落在警告或无效区间，而非高分 |
| 只做半程、未回正 | 骨盆倾斜 | 不应被计为完整次数 |
| 开头/结尾存在调整姿势 | 骨盆倾斜 | 不应多计假动作 |
| 不同拍摄距离、遮挡、侧身角度 | 对应真实动作 | 用于评估阈值在实际环境中的稳定性 |

## 9. 当前风险与边界

1. **阈值来自有限样本**：2.5°/3.0° 已能隔离当前发现的缩腹误选样本和标准骨盆样本，但仍需更多真实患者、不同体型和机位样本验证；
2. **关键点质量仍是基础前提**：遮挡、视角过斜、身体未完整入镜可能导致结果进入人工复核，而不应被解释为动作质量差；
3. **模板优先级高于代码默认值**：数据库中启用的模板会覆盖默认常量。发布前必须确认启用版本的阈值正确；
4. **重新分析会覆盖当前视频级评分和分次结果**：它用于修正当前结论、补齐模板来源；若未来需要保存“每次历史运行的完整评分快照”，应将分次结果关联到 `analysis_run`，而不是只保留视频当前结果。
